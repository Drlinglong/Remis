# 火星求生英／简中／正体术语表

这是 Remis 随版本发布的可复用词典资源，不是游戏汉化 Mod。解压即可阅读；
无需安装 Remis，也不会修改游戏文件。每次 Remis release 都应附带此资源包。

词典资源版本：**2026.10.08.1**。资源版本独立于 Remis 程序版本；
词典没有变化时，新版程序继续附带相同资源快照，不能声称术语已重新审阅。

## 内容

- `surviving-mars.en-zh-CN.json`：1,711 条英文／官方简中提取术语。
- `surviving-mars.en-zh-CN-zh-TW.json`：278 条英文／简中参考／正体译法，
  保留别名、概念身份、语境限定、置信度与审阅状态。
- 同名 CSV：打包时生成，UTF-8 BOM，可用 Excel 或文本编辑器查看。
- `SOURCES.json`：来源说明及致谢。
- `manifest.json`：资源版本、程序 release 版本及各文件 SHA-256。

这两份词典覆盖范围不同，不应按英文字符串直接合并。正体表的简中列是参考，
允许存在空值，不自动从同名概念补齐。一个英文词可能在不同语境代表不同物件。

正体库共有 282 条：34 条人工确认、110 条经过模型审阅、134 条候选、
4 条待定。此次发布纳入前 278 条，四条待定词不进入可用词典。
简中 1,711 条的 `candidate` 表示提取候选，并非另外经过人工校订。
`approved` 表示本项目人工决定；`reviewed` 表示模型审阅；
置信度是审阅优先级，不是准确率。发布附件不等于全量人工或台湾母语认证。

## 使用边界

CSV 用于阅读、比较和制作其他工具的输入。JSON 的 `import_payload` 沿用
Remis 高级术语导入契约；其中 `approved: false` 默认不授权导入。
支持该接口的开发版可在 preflight 后将 `import_payload` 作为
`POST /api/agent/glossaries/terminology` 的请求，获得用户授权再设为 true。
旧版本未提供该接口时仍可阅读附件，不宣称已有 GUI 文件导入入口。
导入会创建独立标准词典，不覆盖原主词典；后续编辑使用已有词典界面。

不要把整表当作全局查找替换规则：例如独立出现的 Explorer 应结合载具语境判断。
保存的 `context_keys`、`sense` 与别名是翻译约束的一部分。
正式冻结及模型工作流是否执行这些约束，以对应 Remis 版本的能力接口为准。
