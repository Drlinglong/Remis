# Remis Agent Preview interview fixture

`Vic3_Agent_Preview_Demo` is a deliberately small, public-safe Victoria 3 mod
used only to demonstrate the existing approval-gated `localize_mod_v1` path.
It contains no provider credential, personal path, private mod content, or
pre-generated model output.

The Agent Preview build extracts it to its isolated application data directory:

`%APPDATA%\RemisAgentPreview\demos\Vic3_Agent_Preview_Demo`
