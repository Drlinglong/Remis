# 建立和维护官方参考语料库

官方参考语料库把你电脑上 Paradox 游戏的官方本地化文件一次性做成 Remis 的本地 SQLite 索引。之后翻译大型 Mod 时，Remis 可以直接复用原文完全一致的官方译文，减少模型调用并保持官方术语一致。

## 自动检测并建立

1. 打开“设置 → 系统维护”；
2. 在“官方参考语料库”中点击“检测游戏并建立语料库”；
3. 在弹窗中检查检测到的游戏和本地化目录；
4. 勾选本次要建立或更新的游戏；
5. 确认后等待任务完成。

建库或删除可能需要数分钟。进度窗口会按游戏显示当前阶段；建库时还会显示已处理文件数和已索引条目数。你可以关闭进度窗口或切到别的页面，任务会在后台继续；返回设置后，Remis 会恢复正在运行的任务，不需要再次点击按钮。

自动检测只检查 Steam 已登记的库和受支持游戏，不会扫描整块磁盘，也不会自动启动 Steam。进入设置页本身不会开始扫描。

## 手动选择目录

如果自动检测没有找到游戏，可以在对应游戏行选择目录并建立。请选择游戏档案要求的官方目录，而不是 Mod 目录：

- Victoria 3、Crusader Kings III 使用 `<游戏目录>/game/localization`；
- Stellaris、Hearts of Iron IV、Europa Universalis IV 使用 `<游戏目录>/localisation`；
- Europa Universalis V 的官方文本分布在 `game`、`jomini`、`clausewitz` 的多个 `localization` 模块中，Remis 会把这些模块聚合成同一个游戏语料库。

Remis 会按所选游戏的内置官方安装档案验证准确拼写和目录层级；不同游戏的规则不同。自动发现与手动选择都必须解析到 Steam `steamapps/common` 下的游戏安装目录，任意 Mod 的本地化目录不会被当作官方语料来源。

## 更新或重建

游戏更新后，语料库卡片可能显示“有更新可用”。点击该游戏的重建／更新操作会重新读取当前官方目录，并在完成后激活新索引。

索引显示旧版本并不代表翻译一定不安全：Remis 仍要求 key、源语言和原文逐条完全匹配。但及时重建可以获得新版本新增或修改的官方译文。

## 解除绑定并完全删除

点击某个游戏的“删除语料库”后，Remis 会再次确认。确认后会删除：

- 该游戏的当前绑定；
- 该游戏在 Remis SQLite 中保存的所有官方参考集合；
- 这些集合中的索引条目。

这个操作不会删除或修改 Steam 游戏文件、Mod 文件或翻译项目。删除后可以再次自动检测或手动选择目录重建。

## 如何理解任务结果

- **已完成**：所选游戏全部处理成功；
- **部分失败**：至少一个游戏成功、至少一个失败；成功建立的库仍可使用；
- **失败**：本次没有游戏成功，按失败游戏显示的原因检查目录权限、文件状态或数据库。

如果在另一个页面再次发起建库，Remis 不会启动第二个 SQLite 写入任务，而会显示已经运行的同一任务。

## 翻译时会发生什么

语料库准备好后，初次翻译和增量翻译会在模型调用前执行精确匹配。只有 key、源语言、源文本和目标语言均满足条件才复用；目标语言缺失、重复冲突或文本不同的条目仍按正常流程翻译。

官方语料库未建立时，Remis 会提示你可以前往系统维护建立，也允许本次不使用参考库继续。它不会在翻译开始时擅自扫描游戏目录。
