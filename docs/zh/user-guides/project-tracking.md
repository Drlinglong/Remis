# 项目追踪：监控 Mod 更新

> 侧栏入口：**「项目 → Mod 监控」**。
> 用来持续监控某个 **Mod 在磁盘上的路径**，发现本地化文件有变化后，方便你进入 **增量翻译**。
> 它 **不是** 项目管理里的任务看板，也 **不会** 修改或删除被监控文件夹里的任何文件。

---

## 1. 项目追踪适合干什么？

| 适合 | 不太适合（请用别的功能） |
|------|--------------------------|
| 创意工坊 / 本地 Mod 经常更新，想知道「本地化文件变了没」 | 第一次建汉化项目 → [从零开始](getting-started.md) |
| 变化后跳去只翻新增部分 | 全量首次翻译 → **初次翻译** |
| 让 Remis 在运行时按间隔自动扫路径 | 手改某一句译文 → [校对](proofreading.md) |
| 关联到已有 Remis 翻译项目 | 把汉化装进游戏 → [一键部署](one-click-deploy.md) |

界面副标题的含义可以概括成：

> 给 Remis 添加需要持续监控的 Mod 本地路径；本地化文件变化后，一键跳到增量更新。

---

## 2. 和「项目管理」「增量翻译」的关系

```text
项目管理：在 Remis 里登记「我在做哪个汉化项目」
        ↓
项目追踪：盯住「原版 / 创意工坊 Mod 文件夹」有没有更新
        ↓
增量翻译：确认有变更后，只处理新增/改动的本地化内容
```

| 功能 | 管什么 |
|------|--------|
| **项目管理** | Remis 内部的项目记录、路径、部署等 |
| **项目追踪** | 外部 Mod 目录是否变化（只读扫描） |
| **增量翻译** | 在已有归档基线的前提下，只翻更新部分 |

建议：先在 **项目管理** 里建好对应项目，再在项目追踪里 **关联** 该项目；否则「开始增量更新」可能不可用。

一个规范化目录只应建立一个监控项，一个项目通常也只需要关联一个监控项。当前版本尚未
完全阻止重复登记，请不要为同一路径重复创建。

更完整的增量流程见 [增量翻译](incremental-update.md)。

---

## 3. 推荐操作顺序

1. 左侧打开 **「项目追踪」**。
2. 点 **「添加需要追踪的新项目」**。
3. 填写：
   - **名称**：方便你辨认的名字
   - **路径**：要监控的 Mod 根目录（常见为创意工坊路径）
   - **关联项目**：选 Remis 里对应的翻译项目（也可先「未关联」）
   - **启用定时扫描**：Remis 运行时是否按间隔自动扫
   - **扫描间隔**：分钟 / 小时 / 天
4. **保存**。
5. 需要时点某一行的 **「扫描」**，或勾选多项后 **「扫描选中项」**。
6. 状态变成 **「有变更」** 且已关联项目时，可点 **「开始增量更新」** 进入增量流程。

---

## 4. 路径怎么填？

路径应是 **Mod 在本地磁盘上的存放地址**，例如：

```text
...\SteamLibrary\steamapps\workshop\content\<游戏ID>\<创意工坊物品ID>\
```

也可以是你自己拷贝的完整 Mod 文件夹。

| 说明 | 内容 |
|------|------|
| 监控对象 | 该文件夹下的 **本地化相关文件** 是否变化 |
| 安全承诺 | **Remis 不会修改或删除** 该路径下的任何文件 |
| 选择方式 | 可点 **「浏览」** 选目录，不必手敲长路径 |

扫描只关心 `localization` / `localisation` 下的本地化内容。模型、图片、封面和游戏机制
脚本变化不会触发告警。只改文件时间而内容不变也不会告警。

---

## 5. 状态分别是什么意思？

| 状态（界面文案） | 含义 |
|------------------|------|
| **未扫描** | 还没扫过，或尚无结果 |
| **已建立基线** | 已记下当前文件快照，作为之后对比的起点 |
| **无变更** | 相对上次基线，本地化文件看起来没变 |
| **有变更** | 检测到变化，可考虑做增量翻译 |
| **没有本地化文件** | 路径下没找到可监控的本地化内容；检查是否选错目录 |

列表里还会显示 **最后扫描**、**变更** 数量、**扫描间隔** 等，便于你判断要不要立刻处理。

当前按相对路径比较文件：把内容完全相同的本地化文件移到另一个子目录，可能暂时显示为
“删除一项、增加一项”。这不会改文件；进入增量翻译后仍会按条目判断是否真有新内容。

---

## 6. 定时扫描说明

- 勾选 **「启用定时扫描」** 后：只要 **Remis 在运行**，就会按设定间隔检查该路径。
- Remis **完全退出** 时，不会在后台继续扫。
- 下次启动时，Remis 应补做关闭期间错过的到期扫描。
- 也可随时 **手动扫描**（单行「扫描」或「扫描选中项」）。
- 页面会周期性 **刷新** 列表状态；后台扫描完成后，列表也会更新。

## 7. 常见问题

### 为什么不能「开始增量更新」？

若提示还没有关联 Remis 项目：先 **编辑** 该追踪项，在 **关联项目** 里选中对应翻译项目并保存。

### 扫描说有变更，但我还没建过增量基线？

增量翻译本身还依赖项目侧的归档 / 基线条件。追踪只负责 **发现外部 Mod 变了**；具体怎么只翻新增，请按 [增量翻译](incremental-update.md) 准备好基线后再跳转。

### 为什么同一个变化一直显示？

监控会保留未处理告警，避免下一次“无变化”扫描把它悄悄清掉。产品目标是允许你标记
**已处理 / 忽略**；当前用户界面还没有完整提供这一操作。

### 项目归档后还会监控吗？

产品设计上会继续监控，因为原 Mod 仍可能更新。当前版本归档项目可能同时停用绑定监控，
这是已知实现差距；需要时请到 Mod 监控页重新核对启用状态。

### 会不会误删创意工坊文件？

不会。项目追踪对监控路径是 **只读扫描**。删除假本地化、部署等是其它功能，且需要你在对应界面确认（见 [假本地化](fake-localization.md)、[一键部署](one-click-deploy.md)）。
