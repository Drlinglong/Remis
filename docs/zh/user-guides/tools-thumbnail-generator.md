# 工具：封面图生成器

> 侧栏入口：**「工具箱」**。
> 当前面向普通用户 **默认开放** 的工具是 **「封面图生成器」**（页签名称以界面为准）。
> 用于给汉化 / 创意工坊 Mod 做一张带旗帜、标题等元素的 **封面图**，并导出下载。
> 它 **不负责** 翻译、部署或修改 Mod 内的本地化 yml。

---

## 1. 封面图生成器适合干什么？

| 适合 | 不太适合 |
|------|----------|
| 为汉化版做 Steam 工坊 / 发布用封面 | 翻译正文 → **初次翻译** / [校对](proofreading.md) |
| 快速叠国旗、标题文字、Logo | 装进游戏 → [一键部署](one-click-deploy.md) |
| 导出一张合成好的图片到本机 | 改游戏脚本或逻辑 |

界面说明可概括为：添加国旗、文本或自定义标识；也可一键添加多国旗帜，做成类似维多利亚 3 风格的多语言封面示意。

---

## 2. 怎么打开

1. 左侧导航点 **「工具」**。
2. 在工具页顶部页签中选择 **「封面图生成器」**（默认往往就在这一页）。

若你看到其它工具页签但点不开或没有：那些可能是 **未对普通用户开放** 的实验功能，本文不介绍。

---

## 3. 界面三块分别是什么？

常见布局：

| 区域 | 作用 |
|------|------|
| **工具箱** | 上传图、加旗帜、加文字、重置/删除画布等操作按钮 |
| **画布** | 实时预览；可拖动元素调整位置 |
| **属性检查器** | 选中某个元素后，改文字内容、字号、字体、颜色、宽高等 |

---

## 4. 推荐操作顺序

1. **准备背景**
   - 设 **背景颜色**，或
   - **上传背景图片**
2. **上传 Mod 图片 / Logo**（也可把 Logo **拖进** 画布区域预览）。
3. 需要时：
   - **添加国旗**（单个），或
   - **一键添加所有旗帜**（快速铺一排语言旗）
4. **添加文本**，在属性里改成你的标题（如汉化名、版本说明）。
5. 需要时 **上传自定义标识**（徽章、图标等）。
6. 在画布上 **拖动 / 缩放** 各元素到满意位置。
7. 点 **「下载封面图」**，保存到本机。
8. 推倒重来可用 **「重置画布」** 或 **「删除画布」**（以界面按钮为准，注意会丢掉当前编排）。

---

## 5. 元素怎么改？

1. 在画布上 **点选** 文字、图片或旗帜。
2. 右侧 **元素属性** 会出现对应选项，例如：
   - 文本：内容、字体大小、字体、颜色
   - 图片类：宽度、高度等
3. 不需要的元素可 **删除元素**。

操作以当前版本界面文案为准；不同主题下样式可能不同，功能相同。

---

## 6. 导出与用途

- **下载封面图** 得到 512 × 512 的 `thumbnail.png`，供你上传到创意工坊、README、
  发布页等。512 是 Remis 当前兼容默认值，不是 Steam 的通用尺寸上限。
- Remis **不会** 因为你在这里点了下载，就自动改 Steam 工坊上的封面；上传仍由你在 Steam / 发布渠道完成。
- 封面生成与 **一键部署**、**翻译任务** 无强制绑定，可随时单独使用。
- 当前版本不会自动读取项目原封面，也不能直接保存或覆盖项目输出目录；这些是后续的小型
  项目集成功能。

上传非正方形背景时，当前会按比例完整放入画布，并用背景补齐空白；当前还不能让你切换为
“裁剪填满”。

## 7. 常见问题

### 只有封面图，没有别的工具？

是的：当前用户文档与常规发行配置下，**工具** 页面向用户介绍的重点就是 **封面图生成器**。其它实验页签若未开放，请忽略。

### 拖放没反应？

确认拖的是图片文件，并拖到画布/上传提示区域；也可改用按钮 **上传**。若仍失败，查看 [日志与诊断](logs-and-diagnostics.md)。

### 字体不好看 / 缺中文字体？

生成器提供若干系统常见字体选项。若中文显示异常，可换列表中的其它字体，或先在外部做好字再当图片贴上。

### 可以让 AI 帮我生成素材吗？

可以先在你选择的外部图片模型中生成素材，再手动导入。Remis 当前不会在封面工具里调用
付费 AI，也不会要求你把图片模型密钥交给它。

### 会覆盖原 Mod 的 thumbnail 吗？

不会。当前只下载文件。未来即使加入项目保存，也只能在展示准确路径并由你确认后覆盖
**翻译输出目录**，绝不能修改原 Mod 目录。
