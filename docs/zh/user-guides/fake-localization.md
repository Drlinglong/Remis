# 假本地化（假中文 / 假多语言）是什么？

> 面向玩家与汉化使用者。
> 当你做好了汉化包，游戏里却仍显示英文（或仍像没汉化），**假本地化**往往是头号嫌疑人。

## 1. 一句话解释

**假本地化** = 原版 Mod 里那些「假装成中文（或其他语言）、其实仍是原文」的本地化文件。

它们能让 **没有汉化包** 的玩家勉强玩下去（至少看到英文而不是一堆 `some_event_title` 这种键名），但会 **挡住真正的汉化 Mod**，让你的翻译读不进去。

---

## 2. 推荐做法：优先用 Remis 内置功能

**请先使用客户端里的功能，不要一上来就手动删创意工坊文件夹。**

部署按钮与路径核对的操作专文：**[一键部署](one-click-deploy.md)**。

Remis 已提供：

| 界面文案（中文） | 作用 |
|------------------|------|
| **一键部署** | 把译好的汉化包部署到游戏读取的 Paradox 用户 `mod` 目录 |
| **删除假本地化文件** / 部署对话框中的清理选项 | 在**原始模组目录**（多为 Steam 创意工坊缓存）中，自动删除除原始语言以外的假语言文件夹与冲突文件 |
| **清理假本地化与部署**（部署对话框） | 可先确认路径，再选择「直接部署」或「清理假本地化后再部署」 |

### 2.1 建议操作顺序

1. **先完成翻译**，确认项目里已有译好的输出包。
2. 在项目界面点击 **「一键部署」**（或同等入口），打开 **「清理假本地化与部署」** 对话框。
3. 确认两项路径（客户端通常会自动探测）：
   - **目标部署目录**：汉化包要放到的 Paradox 用户 mod 目录
   - **原始模组目录**：Steam 创意工坊 / 原版 Mod 所在位置（清理假本地化时需要）
4. 若自动探测失败：用对话框里的 **「自动寻找原始模组」** 或 **「浏览…」** 手动选对文件夹。
5. 按需选择：
   - 只需安装汉化、原版没有假文件干扰 → **「直接部署翻译」**
   - 游戏里仍被英文/假中文挡住 → 使用 **删除假本地化** 相关按钮（例如 **「寻找并删除原始模组的假本地化文件」** / **「删除路径下的假本地化文件」**），并在确认风险后再执行
6. 到游戏启动器中启用 **原 Mod + 汉化 Mod**，并确认 **加载顺序**（汉化一般在原版之后 / 更优先，以启动器为准）。
7. 进游戏检查文本是否已是译文。

### 2.2 关于「删除假本地化」的风险提示

清理会 **直接修改原始模组目录**（常见为创意工坊缓存）：删除除原始语言（如 `english`）以外的语言文件夹及相关冲突文件。

- 客户端会弹出 **高风险确认**，请读完再点确认。
- Steam 之后可能因校验 **重新下载** 被删文件，导致假本地化「复活」——若发生，可在 Remis 中 **再次清理并部署**，或改用本地 mod 目录管理（见下文「内置功能仍不够时」）。
- 路径选错可能误删别的 Mod：务必确认对话框里的 **原始模组目录** 指向当前这个 Mod。

### 2.3 为什么优先用内置功能？

- 会按项目的 **源语言** 决定保留哪一套语言目录，减少手误
- 部署目标默认识别 Paradox 文档下的 `mod` 路径
- 尽量自动关联创意工坊 / 原版路径
- 有确认步骤与结果提示，比纯手删更安全、可重复

## 3. 为什么作者要做假本地化？（背景）

Paradox 游戏的文本按语言分子目录，例如：

```text
localization/
  english/
  simp_chinese/
  french/
  ...
```

多数 Mod 作者只会写 **一种原文**（常见是英文）。常见取巧做法是把英文复制成 `simp_chinese` 等，或让中文客户端去读「目录像中文、内容仍是英文」的文件。

这样没汉化也能看到英文句子，而不是满屏 key——这就是 **假中文 / 假本地化**。
它们多在 **原 Mod 目录** 里，读取优先级往往高于汉化补丁，所以会挡住 Remis 生成的真汉化。

---

## 4. 典型症状（符合任一条都值得先走「一键部署 + 清理」）

- 启动器里已启用原版 + 汉化，顺序也对，正文仍是英文
- 只有部分文本翻了，其它仍像原版假中文
- 创意工坊更新后，汉化又突然失效
- 以前手动删过假文件，Steam 又拉回来了

加载顺序与假本地化是 **两层问题**，建议都查：先 Remis 部署/清理，再核对启动器顺序。

---

## 5. 内置功能仍解决不了时：再考虑手动

仅在下列情况再动手改文件夹：

- Remis 无法探测或你无法在对话框中指定正确的原始模组路径
- 清理报告成功，但游戏仍不读汉化，且已排除加载顺序、未启用汉化等问题
- Steam 反复强制恢复假文件，需要改用本地拷贝/覆盖等进阶策略

### 5.1 手动清理（备用）

1. 找到原 Mod 目录（创意工坊形态示意）：

```text
SteamLibrary\steamapps\workshop\content\<游戏ID>\<Mod创意工坊ID>\localization\
```

2. **只保留原始语言文件夹**（如英文 Mod 只留 `english`），删除其它语言文件夹。
3. 先备份再删；游戏 ID、Workshop ID 以你本机路径为准。

### 5.2 手动覆盖 / 本地 mod 目录（备用）

- 将汉化内容覆盖进原版 Mod（减少缺文件校验反复拉回）
- 或将整理好的包放到 `Documents\Paradox Interactive\<游戏名>\mod` 再启用

这些步骤容易出错；**能在 Remis 里完成时，请继续用一键部署与删除假本地化。**

## 6. 和 Remis 的关系（给帮助说明 / Copilot）

| 正确引导 | 避免 |
|----------|------|
| 先 **一键部署** | 一上来让用户去 Steam 目录手删 |
| 对话框中确认路径后 **删除假本地化** | 假装「聊天里已经删好了」 |
| 写操作须用户在 UI **确认风险** | 静默改创意工坊目录 |
| 仍失败再给手动步骤 + [日志](logs-and-diagnostics.md) / GitHub | 让用户改 Remis 源码 |

普通客户端 **不能修改 Remis 程序本身**；若内置部署/清理异常，请带版本与日志到
<https://github.com/Drlinglong/Remis/issues> 反馈。

---

## 7. 推荐排查顺序（总览）

1. 项目是否已翻译出完整汉化包
2. Remis：**一键部署**（需要时勾选/执行 **删除假本地化**）
3. 游戏启动器：启用原版 + 汉化，检查加载顺序
4. 仍不行：核对对话框路径是否指对 Mod；可再执行一次清理与部署
5. 仍不行：再考虑第 5 节手动步骤
6. 程序报错或路径总探测失败：看 [日志与诊断](logs-and-diagnostics.md)，必要时开 Issue
