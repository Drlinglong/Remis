# 新词审判庭：挖词与审词

> 侧栏入口：**「质量与术语 → 新词审判庭」**。
> 用 AI 从项目文本里 **挖出可能的新术语**，再由你在「审判庭」里 **批准写入词典** 或 **驳回**。
> 它帮助统一专有名词，**不会**在聊天里直接改你的 yml 译文文件。

---

## 1. 新词审判庭适合干什么？

| 适合 | 不太适合（请用别的功能） |
|------|--------------------------|
| Mod 里大量生僻人名、地名、势力名 | 第一次建项目 → [从零开始](getting-started.md) |
| 希望翻译前/中统一术语 | 改某一句已有译文 → [校对](proofreading.md) |
| 把审过的词写入主词典或 **项目专属词典** | 修 `$变量$` / 颜色标签 → [智能工坊](agent-workshop.md) |
| 人工确认 AI 建议译名 | 进游戏安装 → [一键部署](one-click-deploy.md) |

和 [词典与词汇表](glossary.md) 的关系：

- **词汇表管理**：日常查看、编辑已有词条
- **新词审判庭**：批量 **发现候选词 → 你裁决 → 写入词典**

---

## 2. 两个页签分别是什么？

| 页签 | 作用 |
|------|------|
| **挖掘控制台** | 选项目、（可选）文件、API 与目标语言，启动 AI 挖词 |
| **审判庭** | 逐条查看候选词、改建议译名、批准或驳回 |

典型顺序：

```text
挖掘控制台：开始挖掘
        ↓
（后台跑完，可能产生 API 费用）
        ↓
审判庭：案卷列表 → 审一条批一条
        ↓
词条进入主词典 / 项目专属词典
```

挖掘完成后，界面往往会 **自动切到审判庭**，方便立刻审。

---

## 3. 挖掘控制台：怎么跑一轮

1. 打开 **新词审判庭 → 挖掘控制台**。
2. **选择项目**（必须是已在项目管理里建好的项目）。
3. （可选）**选择要挖掘的文件**；**留空**表示扫描整个项目。
4. 选择 **API 供应商** 与 **模型**（需已在 **设置 → API** 配好，见 [Provider 速查](provider-setup-index.md)）。
5. 选择 **目标语言**（AI 用该语言给建议译名）。
6. 阅读费用提示后，点 **「开始挖掘」**。
7. 等待状态变为完成；可看进度、发现数量、与已有词典重复的数量。

### 注意

- 挖掘会 **调用 LLM**，可能产生 **API 费用**。
- 需要可用的网络 / 本地模型服务；失败时可看 [日志与诊断](logs-and-diagnostics.md)。
- 开始挖掘时，Remis 常会 **自动为该项目准备项目词典** 并绑定（也可在项目管理的「项目词典」页签查看）。

---

## 4. 审判庭：怎么批词

1. 打开 **审判庭** 页签，确认 **当前项目** 正确。
2. 左侧 **案卷列表** 里点一条候选词。
3. 查看：
   - **候选词汇**（原文侧术语）
   - **AI 分析** / 上下文证据
   - **最终翻译**（批准前可编辑）
4. 若提示与已有词典 **重复**，先选处理方式，例如：
   - **沿用现有词典译法**
   - **创建仅限本项目的覆盖译法**
   - **标记为本项目中的新义项**
5. 选好 **目标词库**（主词库 / 项目专属词典等，以界面选项为准）。
6. 点 **「批准术语」** 写入词典，或 **「驳回 / 忽略」** 丢掉该候选。

全部处理完后，案卷会显示「全部处理完毕」一类提示。

---

## 5. 批准之后词在哪里？

| 去向 | 之后怎么用 |
|------|------------|
| **主词典** | 该游戏下更通用的术语，可在 **词汇表管理** 中继续维护 |
| **项目专属词典** | 只服务当前 Mod；翻译流水线可优先吃到这些专名 |

项目是否已绑定项目词典，可在 **项目管理 → 该项目 → 项目词典** 查看、绑定或解绑。详见 [词典与词汇表](glossary.md)。

## 6. 常见问题

### 必须先翻译完才能挖词吗？

不强制。常见做法是：**有项目与原文** 即可挖词；也可在翻译中途补挖。审过的词越早进词典，后续译文越一致。

### 候选词和主词典重复怎么办？

界面会标 **重复** 并要求你选择：沿用旧译、项目覆盖、或新义项。不要不看就全批，避免和全游戏术语打架。

### 挖完了案卷是空的？

可能：本轮没有新候选、都已审完、或选错了项目。可换项目、再挖一轮，或到词汇表管理确认是否已写入。

### 小助手能替我批词或改词典文件吗？

当前 Help 小助手 **不能** 代替你在审判庭点批准，也 **不能** 直接改磁盘上的词典文件。请在本页完成裁决。
