# 智能工坊：自动修复格式问题

> 侧栏入口：**质量与术语 → 格式修复台**。

智能工坊是翻译后的格式安全护栏。它检查变量、标签、文件结构和源语言标点残留，让已经通过验证的修复自动写回翻译成果。

它不负责文风、氛围、术语选择或普通错译。需要调整译文内容时，请使用[校对](proofreading.md)和[词典](glossary.md)。

## 什么问题适合交给它

常见可检测问题：

- `$...$`、`[...]`、游戏命令或占位符损坏／缺失；
- 颜色标签、格式标签不配对；
- 引号等本地化文件结构错误；
- 源语言标点残留在目标语言译文中；
- 游戏规则已经能够明确判定的其它格式错误。

以下问题不归智能工坊：

- 译文不够自然或不符合角色口吻；
- 普通错译、漏译或术语不统一；
- 想重写整句、整段或整份文件；
- localization key 本身损坏。

损坏 key 可以被扫描出来，但 Remis 不能自动修 key，需要人工处理文件结构。

## 翻译后的自动修复

初次翻译和增量翻译默认启用内嵌格式修复：

1. 翻译文件生成后，Remis 扫描格式问题；
2. 没有问题时直接跳过，不额外调用模型；
3. 有问题时，只把检出的条目送给格式修复模型；
4. 候选通过验证后自动逐条写回；
5. 有限重试结束后，显示修复数量和剩余数量。

默认沿用本次翻译使用的供应商、模型、批大小、并发和 RPM。展开高级设置可以关闭内嵌工坊，或者为它指定另一组模型设置。

内嵌修复不要求逐条确认。你在开始翻译前确认的配置已经包括这一步。

## 主动进入格式修复台

已有译文时，也可以单独运行：

1. 选择项目。
2. 点击**扫描项目错误**。
3. 检查问题条目、文件、错误类型和当前译文。
4. 选择供应商和模型。
5. 点击开始修复。
6. 在确认弹窗中核对项目、本次问题数量、供应商和模型。

确认后，Remis 会调用模型，并把验证通过的结果自动逐条写回项目翻译文件。这个确认可能涉及模型费用和文件修改。

扫描本身不会调用模型，也不会修改译文。需要最新结果时重新扫描；缓存只用于快速恢复上次发现的问题。

## 批量修复的结果

运行过程会进入 Task Center。即使离开页面，也可以按准确任务 ID 找回进度和结果。

结束后会显示：

- 检测到多少问题；
- 成功修复多少；
- 仍失败多少；
- 每条成功修复的前后内容；
- 可用时显示修复报告路径。

全部问题通过为完全成功。部分问题在有限重试后仍未解决时，成功项会保留，失败项继续留在问题列表。你可以重新扫描，再换模型运行一轮，或者人工处理。

## 单条修复

在问题明细中点击单条 AI 修复时：

1. 核对源文、当前译文、错误类型、供应商和模型；
2. 点击修复按钮，确认这一次模型调用和自动写回；
3. 后端生成候选、验证并写入该条目；
4. 返回结果中查看分析、候选和报告。

3.1.0 结果弹窗仍显示“应用修复”，但成功响应到达时后端已经完成写回；这个按钮目前只是关闭结果并从当前问题列表移除，不是第二次写入确认。文案将在后续收敛。

## 自动写回会改什么

智能工坊只应修改：

- 本次扫描选中的条目；
- 该 key 引号内的译文值；
- Remis 管理的项目翻译成果。

它不应修改：

- 同文件中的无关条目；
- localization key；
- 原始 Mod 或创意工坊文件；
- 词典、项目管理状态或部署目录。

它也不会自动部署。

## 失败后怎么办

反复失败通常意味着：

- 模型能力不足；
- 错误超出格式修复范围；
- 源文上下文缺失；
- key 损坏；
- 文件无法定位、写入或读回。

建议：

1. 查看成功数和剩余数；
2. 重新扫描，确认当前实际问题；
3. 换一个更可靠的模型再运行；
4. key 损坏或仍无法解决时人工处理。

3.1.0 有一个已知实现缺口：独立工坊某些路径在写入后才做最终验证，最终验证失败时未必恢复旧译文。若任务报告写回后验证失败，请立即检查该条目的当前内容，不要只看“失败”状态推断旧译文一定没变。

## 为什么不让用户逐条审批

变量、标签和标点问题都有确定性检查。让用户逐条批准机器已经能够验证的格式修复，只会增加阻力。正确边界是：

- 开始前确认项目、问题范围和模型调用；
- 通过验证的修复自动写回；
- 未通过的停止并报告；
- 不允许把格式修复扩大成语义重写。

## 常见问题

| 现象 | 处理 |
|---|---|
| 没有发现错误 | 当前格式规则下没有问题；文风问题请去校对 |
| 一直看到旧扫描结果 | 修改文件后重新扫描 |
| 部分问题反复失败 | 换模型；仍失败则人工处理或确认是否超出范围 |
| key 损坏 | Remis 不能自动修 key，需要人工编辑文件结构 |
| API 失败或限流 | 检查 Provider 设置，降低并发／RPM |
| 想修普通错译 | 使用校对，不要用格式修复台 |
| 修复结束后想玩游戏 | 回项目页面部署；智能工坊不会自动部署 |
