# 项目管理

> 侧栏入口：**「项目 → 项目管理」**。一个项目代表某个 Mod 的长期汉化工作空间。

Mod 更新、改名、移动文件夹或增加另一种目标语言时，通常继续使用原项目，不必重新建项。

## 创建项目

1. 点击 **「新建项目」**。
2. 填写项目名称，选择 Mod 根目录、游戏和源语言。
3. 选择导入方式：
   - **复制**：把支持的 Mod 内容复制到 Remis 管理的工作目录；
   - **引用**：继续使用你选择的原目录。
4. 创建后核对项目名称、游戏、源语言、实际路径和文件清单。

项目只绑定一个源语言。目标语言在初次或增量翻译时选择，因此同一项目可以逐步产生多种
语言的译文。当前不要让同一目录重复创建多个项目；它们会争用项目配置文件。

如果你已经有译文，当前先完成建项，再按[导入已有译文](import-existing-translations.md)
登记并上载；创建窗口还不能直接选择已有译文目录。

## 项目详情能做什么

- 查看磁盘上实际发现的文件及文件数量；
- 把文件标记为待处理、施工中、校对中、暂停或完成；
- 写项目备注；
- 修改游戏、源语言或项目路径；
- 刷新文件，或明确执行元数据检验与重建；
- 查看项目历史、格式校验结果和项目词典；
- 从项目现场进入校对；初次翻译、增量翻译和部署也以项目为工作对象。

**刷新文件是只读操作。** 它重新读取磁盘清单，不等于上载翻译、建立归档或修复 sidecar。

## 路径或文件在外部变化

磁盘文件是最终事实。如果 Mod 文件夹被移动、删除或无法读取，Remis 应显示路径异常，
而不是把项目当成“空项目”。确认新的目录后再替换路径并继续。

如果你只是想让 Remis 重新看见外部复制进来的文件，先点 **刷新文件**。需要重建
`.remis_project.json`、文件看板或格式错误缓存时，再使用 **元数据检验/重建**。

## 归档和恢复

- **归档**：把不常用项目移出日常列表，资料仍保留。
- **恢复**：让归档项目重新回到活动列表。

归档不是删除，也不应影响该项目已经配置的 Mod 监控。

## 删除项目

删除项目会永久移除 Remis 中的项目记录和绑定关系。操作前会要求确认。

如果勾选同时删除磁盘目录，务必核对界面展示的完整路径：Remis 会递归删除该目录，且无法
可靠判断它是工作副本还是你的原 Mod 目录。该选项应默认关闭，并需要单独确认。

项目删除后，绑定到它的监控项会移除，词典不再绑定到幽灵项目。翻译归档、词典本身和
任务中心日志有各自生命周期，不应因为删项目而自动消失。
