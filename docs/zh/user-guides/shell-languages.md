# 套壳语言与项目维护

游戏不支持意大利语等目标语言时，可以在初次翻译配置中开启套壳，填写实际语言名称、选择游戏支持的语言壳，并设置输出前缀。例如：Italian、英语、`it-`。游戏使用英语加载这些意大利语文本。

**强烈建议为每一种实际套壳语言建立独立项目。** 创建项目时无需决定是否套壳；开启套壳后会出现可展开的提示，不要求确认，也不会禁止继续使用当前项目。项目管理检测到 `custom` 归档语言时也会显示简短提示。

同一项目的自定义语言共用 `custom` 归档标识。填写“繁体中文”“正体中文”或其繁体写法不会创建不同基线，但把实际语言从意大利语改成另一种语言，也不会自动隔离已有成果。套壳名称是翻译指令，不是独立的基线身份。

需要翻译另一种套壳语言时，建议从原始 Mod 重新以复制模式导入一个项目，再配置套壳。不要沿用其他语言项目的翻译目录关联。原来的官方多语言项目可以继续保留；游戏官方支持的多种语言能够在同一项目中共存。

此建议不构成单语言强制限制，不改变现有项目，也不自动迁移归档。启动器应启用原 Mod 和翻译 Mod，并使用选定的语言壳。最终兼容性仍需在游戏中验证。
