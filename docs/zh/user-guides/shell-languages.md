# 套壳语言与项目维护

游戏没有提供你想要的语言时，可以使用“套壳翻译”。例如，把 Mod 翻译成意大利语，但让游戏通过 English 选项显示这些意大利语文本。

**强烈建议为套壳翻译单独新建一个项目，专门维护这一种语言。** 在同一个项目里切换套壳语言，可能让保存的翻译记录混在一起。以后原 Mod 更新时，Remis 可能用错之前的译文，增加检查和返工。

例如，一个项目已经用于意大利语翻译，后来又用来翻译泰语，后续更新就可能混用这两种语言的记录。更稳妥的做法是为泰语另外建一个项目。仅把“繁体中文”改写成“正体中文”之类的名称，不会另外创建一份翻译记录，也不能用改名来分开管理不同语言。

操作时，从原 Mod 新建项目并选择复制导入，建议在项目名称中注明语言。然后在初次翻译配置中开启套壳，填写实际语言、游戏语言选项和输出前缀，例如 Italian、英语、`it-`。需要另一种语言时，再从原 Mod 新建项目，不要把之前的翻译文件夹添加进来。

创建项目时不用提前决定是否套壳；选择套壳翻译时会看到提示，项目管理页面也可展开查看原因。你仍可选择继续使用当前项目。游戏本身支持的多种语言仍然可以在同一项目中维护。

使用时，在启动器启用原 Mod 和翻译 Mod，并选择对应的游戏语言选项。意大利语套英语壳时，游戏语言选 English；最终效果需在游戏中检查。

如需了解为什么会混用记录，可以继续向 Agent 追问。Agent 应先说明实际影响和操作方法，再按追问展开存储和增量更新细节。开发者可查阅 [Agent API 技术参考](../../../.agents/skills/remis-agent/references/api-workflow.md)。
