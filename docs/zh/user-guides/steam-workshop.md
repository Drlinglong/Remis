# Steam 工坊与发布素材

“Steam 工坊”用于管理封面、描述及发布记录。正式 v3.3.0 仍以发布素材管理为主；
当前开发整合版增加了明确批准后的 Steam 上传。以下新增上传步骤适用于开发版，不代表
正式安装包已提供此功能。

## 两个入口

- 左侧一级菜单 **Steam 工坊**：打开跨项目的发布工作区总览；
- **项目管理 → 具体项目 → 更多视图 → 发布素材管理**：只管理当前项目的素材。

两个入口使用同一套数据，不会产生两份互不相通的历史。

## 产品内教学引导

第一次从一级入口打开 Steam 工坊时，Remis 会询问是否开始教学引导。你也可以在任意
时候点击侧栏底部的 **教学引导** 重新打开当前页面的说明。

引导按你所在的位置说明下一个可见操作：

1. 在总览中创建或选择发布工作区；
2. 在 **封面图** 中制作图片并保存候选版本；
3. 在 **工坊描述** 中编辑、预览 BBCode 并保存候选版本；
4. 在 **版本历史** 中检视候选并明确设为采用。

引导不会替你创建工作区、保存版本、调用模型或上传 Steam。它只解释界面和操作结果；
涉及模型生成时仍需要你在确认弹窗中明确批准。

## 发布工作区

发布工作区可以：

- 绑定一个 Remis 项目；
- 暂不绑定项目；
- 选择性填写 Workshop ID；
- 保存多版封面图和工坊描述；
- 分别选择当前采用的封面图和描述。

“游戏”字段不是自由文本。创建或编辑工作区时，应从 Remis 当前支持的游戏下拉列表中
选择；数据库保存稳定的内部游戏 ID，例如 `victoria3`，界面再按当前语言显示游戏名。

Remis 随安装数据提供 **Demo - 测试工作区**。它绑定维多利亚 3 演示项目，包含 Remis
logo 封面 #2，以及中文描述 #1、日文描述 #2。这个工作区用于体验封面、BBCode 预览和
版本历史，不会上传 Steam。首次补种完成后，Remis 不会在后续启动时覆盖你对 Demo 的修改。

创建新工坊物品前没有 Workshop ID 是正常情况，不影响先准备素材。
总览卡片展示项目绑定、Workshop ID、当前采用的封面与描述版本，以及最近更新时间。
创建后可通过工作区卡片上的 **编辑** 补填、替换或清空 Workshop ID；这不会删除已经
保存的封面图或工坊描述版本。进入工作区后，通过三个独立入口处理：

- **封面图**：编辑画布、下载或保存候选版本；
- **工坊描述**：编辑、预览或生成候选版本；
- **版本历史**：统一检视两类资产、筛选版本并明确设为采用。

## 工坊描述

你可以手工编辑 BBCode，安全预览后保存候选版本。候选版本不会自动成为当前采用版本。

若工作区已经填写 Workshop ID，还可以选择模型生成：

1. 在工坊描述主页面外层的配置区，从“API 供应商”下拉菜单选择供应商；
2. 从“模型”下拉菜单选择要调用的模型；
3. 从“描述语言”下拉菜单选择 Remis 提供的 11 种语言之一；
4. 在同一页面的“发布模板”文本框中填写或调整模板；
5. 点击“模型生成”；
6. 在确认弹窗中阅读本次调用摘要，勾选明确批准后点击“确认生成”。

供应商、模型、描述语言和发布模板都在工坊描述主页面外层配置，不藏在确认弹窗内。
确认弹窗只显示本次调用摘要并请求明确批准，不提供配置输入，也不显示并发或 RPM 设置。

Remis 会读取公开的现有工坊描述，调用所选模型，并把结果及源描述快照保存为候选版本。
它不会自动采用结果，也不会上传 Steam。

工坊描述使用与翻译工作流相同的 API 供应商和模型配置；远端供应商未配置密钥时会在
页面提示并阻止生成。本阶段每次只调用一次模型，因此不显示并发数和 RPM 设置。

## 封面图

封面图编辑器会自动恢复当前工作区或项目的本机草稿。点击“保存候选版本”时，Remis
同时保存：

- 可继续编辑的画布结构；
- 实际导出的 PNG；
- 内容哈希和版本来源。

“下载封面图”只保存本机副本，不等于保存版本或上传 Steam。

要保存正式可回溯版本，请点击 **保存候选版本**。候选版本包含可编辑画布和导出的 PNG；
之后在 **版本历史** 中检视并选择要采用的版本。

## 在任务中心跟踪

- 保存封面图时会出现一条任务，图片和可编辑画布都保存成功后显示完成，任一失败则显示失败；
- 生成工坊描述会从调用前开始记录进度，最终显示完成或失败，不会出现部分成功；
- 手动编辑并保存描述候选不会创建任务。

## 版本历史

- 版本历史是工作区内的独立页面，不会堆在编辑器下方；
- 保存候选：创建不可变版本；
- 打开：检视该版本的封面或描述内容；
- 设为采用：指定未来发布默认使用的版本；
- 删除：只可删除未采用的单条候选或历史版本；封面版本会同时移除其受控 PNG 文件；
- 当前采用版本不能删除。先采用另一版本，再删除原版本；
- 其它历史版本不会因切换采用版本而删除。

删除某个版本不会删除其后续候选版本；后续候选不再显示该被删除版本为父版本。删除不可
恢复，因此在删除前请先用 **打开** 确认内容是否仍需要。

## 当前边界

工坊上传暂为**测试功能**，入口和页面标题均标注测试状态。可准备和预览翻译包；直接上传
暂限已配置的开发测试环境，当前安装版尚不支持开箱即用的直接上传。预览、明确批准、
运行时检查与未知结果人工核验继续生效。封面和描述的保存、采用不等于对外上传。

## 备份与恢复

发布工作区采用混合存储：工作区、描述、画布和版本元数据位于 `remis.sqlite`；封面 PNG
位于同一 AppData 根目录下的 `steam_workshop_assets`。备份时必须同时复制数据库和该素材
目录。尚未保存为候选版本的画布草稿位于 WebView 本机存储，清理应用站点数据可能使草稿
消失。


## 测试功能：开发版首次上传

2026-10-14 的整合版已完成 Victoria 3 私密新建条目的真实上传：Remis 收到成功回调，
用户用浏览器打开 Steam 条目并核对内容。其他游戏、更新已有条目、异常恢复及正式安装包
仍需各自验收。上传完成不等于 Mod 已通过游戏内加载检查。

### 先准备 Steam 和 SDK

1. 安装 Steam 桌面客户端并登录，账户需要拥有目标游戏。
2. 从 [Valve 官方 Steamworks SDK 说明](https://partner.steamgames.com/doc/sdk)进入官方获取渠道，
   下载并解压 SDK。当前开发版不附带 Valve 二进制文件，也不能仅靠安装 Steam 客户端完成配置。
3. 找到同时包含 `public/steam/steam_api.json` 和 `redistributable_bin/win64/steam_api64.dll`
   的 `sdk` 目录。启动 Remis 前，在同一个 PowerShell 窗口中设置实际路径：

```powershell
$env:REMIS_STEAM_SDK_DIR = 'J:\steamworks-sdk\sdk'
.\scripts\developer_tools\windows\run-dev.bat
```

上面的目录只是示例，请换成实际路径。设置后需重启 Remis 后端；不需要将 SDK 复制进仓库，
不需要在 Remis 中填写 Steam 密码或 Steam Guard 验证码。未就绪时，发布页会显示准备引导。
也可以点击“首次上传：准备与操作引导”，或侧栏“教学引导”，重新查看步骤。

### 新建一个私密测试条目

1. 创建或选择绑定了项目的工作区，在“封面图”和“工坊描述”中保存并采用版本。
2. 打开“发布”，选择项目已登记且实际存在的翻译输出包。列表为空时，到项目管理检查输出；
   Demo 现成译文会在开发启动时加载，无需为上传测试付费重新翻译。
3. 目标游戏默认按绑定项目选中，显示为“App ID（游戏名）”，可以选择其他当前支持的游戏，
   或使用“手动输入其他 App ID”。当前发布包校验支持维多利亚3、群星、钢铁雄心4、
   欧陆风云4、欧陆风云5、十字军之王3 的 YML 包；不代表其他 Remis 游戏适配器已经支持上传。
4. 选择“新建”“私密”，输入测试标题与更新说明。标签可从建议中选择，也可以输入后按回车添加。
5. 点“生成不可变发布预览”，核对账户、目标游戏、输出文件、封面、描述和可见性。预览不会上传。
6. 勾选批准并上传，等待成功回调和条目 ID，再打开 Steam 条目页面核对实际内容。

### 更新与异常处理

更新时必须主动选择“更新”并填写自己的条目 ID；原作者的 Workshop ID 不会成为默认更新目标。
封面、描述、输出或目标有变化后，应重新生成预览并批准。

“结果未知”或“需要接受协议”时，先去 Steam 核验条目是否已创建，必要时接受协议，再按发布记录中的
人工核验流程登记结果。不要再次新建，以免出现重复条目。页面成功状态仅以 Steam 回调为准。
