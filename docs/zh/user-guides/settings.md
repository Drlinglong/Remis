# 设置：语言、API、Prompt 与版本

> 侧栏入口：**「设置」**。
> 这里配置 **界面语言、主题、API 限速与密钥、翻译 Prompt、版本与日志入口**，以及危险的 **重置项目数据库**。
> 改设置 **不会** 自动开始翻译；配好 API 后，请到项目管理 / 初次翻译等页面执行任务。

---

## 1. 设置页有哪些页签？

| 页签（界面文案） | 干什么 |
|------------------|--------|
| **常规** | 界面语言、主题、全局 API RPM 限制、系统维护（重置库） |
| **API 设置** | 各 AI 服务商的密钥、模型、Base URL 等 |
| **Prompt 设置** | 系统翻译指令覆盖、常驻自定义额外 Prompt |
| **版本信息**（名称以界面为准） | 版本说明、打开日志目录、相关链接等 |

服务商怎么填的细节见 [Provider 配置速查](provider-setup-index.md) 及各 Provider 专文；本文只介绍 **设置菜单本身**。

## 2. 常规

### 2.1 语言

- 选项包括简体中文、English 及其它已本地化语言。
- 修改后界面文案会切换；选择会记在本机，下次启动仍生效。

### 2.2 主题

- 可选多种视觉主题（如浅色 / 深色 / 维多利亚 / 拜占庭等，以列表为准）。
- 只影响外观，不影响翻译结果。

### 2.3 API RPM 限制（全局）

- **RPM** = 每分钟请求数上限，**所有模型共享** 这一全局闸门。
- 调低：更不容易触发服务商限流，但大批量翻译更慢。
- 调高：更快，但更容易 429 / 限流（视服务商而定）。
- 修改后一般会立即提交到后端配置（以你当前版本行为为准）。

### 2.4 系统维护：重置项目数据库

界面会强调：

- **会清空** Remis **内部的项目记录**（数据库里的项目列表等）。
- **主要场景**：数据库异常、卡死、列表错乱时的急救。
- **相对安全点**：说明中写明 **不会删除磁盘上的 Mod / 译文文件本身**。

仍属 **高影响操作**：

1. 点重置前阅读确认框中的 **影响** 与 **仍保留什么**。
2. 确认后执行；成功后界面可能 **整页刷新**。
3. 重置后需要重新在 **项目管理** 里识别 / 创建项目（文件还在的话，内容通常还在磁盘上）。

**不要**把「重置数据库」当成日常清理或卸载手段。

## 3. API 设置

1. 打开 **设置 → API 设置**。
2. 选择要使用的 **服务商**（Gemini、OpenAI 兼容、LM Studio、Ollama 等）。
3. 按需填写：
   - **密钥 (Key)**
   - **模型 (Model)**
   - **接口地址 (URL) / Base URL**（本地与自定义接口常见）
4. 保存（若界面有保存 / 应用按钮，以界面为准）。
5. 有连接测试时，建议先测通再大批量翻译。

### 密钥存在哪？

- 可在设置里填写；也会优先/兼容从环境变量读取（视服务商配置而定）。
- 在界面填写的密钥会保存在 **用户配置目录（如 AppData 下的 Remis 配置）**，而不是塞进你的 Mod 文件夹。
- **不要**把完整 API Key 发给陌生人，也不要粘贴到公开 Issue / 聊天（小助手也不应要求你粘贴完整密钥）。

更细的服务商对照表：[Provider 配置速查](provider-setup-index.md)。

## 4. Prompt 设置

面向希望微调 AI 行为的用户；**改错可能导致翻译失败或质量明显下降**。

### 4.1 系统 Prompt

- 这是批量翻译时发给模型的 **核心指令**。
- 可查看默认（只读参考）与 **当前生效** 内容。
- 高级用户可 **保存系统 Prompt 覆盖**；也可用 **重置为默认** 恢复（不可撤销，需确认）。

### 4.2 常驻自定义 Prompt

- 会作为默认值，填进新翻译任务的 **「额外 Prompt」** 一类字段。
- 适合统一风格，例如：「使用正式语气」「专有名词保持英文」等。
- 可单独保存或清除。

**建议**：没有明确需求时保持默认；先靠词典与校对提高质量，再考虑改系统 Prompt。

## 5. 版本信息

常见能力（以你安装的版本界面为准）：

- 查看当前 **应用版本** / 构建信息
- **打开日志文件夹**（排查闪退、API 失败时很有用）
- 打开相关网页链接（如项目主页、Issue）

日志怎么读：[日志与诊断](logs-and-diagnostics.md)。
错误含义：[错误目录](error-catalog.md)。

## 6. 推荐配置顺序（新用户）

```text
① 设置 → 常规：语言（可选主题）
        ↓
② 设置 → API：填好要用的服务商与模型，能测通先测通
        ↓
③ （可选）设置 → Prompt：仅在有把握时改
        ↓
④ 项目管理 → 创建项目 → 初次翻译 …
```

完整新手路径见 [从零开始](getting-started.md)。

## 7. 常见问题

### 改了 API 为什么翻译还是失败？

- 确认密钥、模型名、Base URL 与服务商文档一致。
- 本地 LM Studio / Ollama 需 **先启动并加载模型**。
- 看日志与 [错误目录](error-catalog.md)。
- RPM 过低会导致极慢；过高可能触发限流——可适当调整。

### 重置数据库后文件还在吗？

按界面说明：重置针对 **内部项目记录**，**不删除** 你磁盘上的 Mod 与译文文件。但 Remis 列表会空，需要重新纳入项目管理。

### 小助手会改我的设置吗？

当前 Help 小助手最多 **引导你打开设置页**；密钥与选项仍由你在设置界面自行填写与保存。
