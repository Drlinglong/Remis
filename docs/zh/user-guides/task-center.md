# 任务中心：查看进度、结果和历史

Task Center 帮你跨页面查看 Remis 正在做什么、哪些任务需要注意，以及已经结束的工作要去哪里继续。关掉当前页面甚至重启程序后，持久化任务仍可以在这里找回。

## 三个入口分别看什么

- **主页“正在进行的工作”**：只显示少量正在运行、需要注意或最近完成的任务。
- **Task Center 抽屉**：后台任务收件箱；查看运行状态、失败提示和最近结果。
- **全部日志**：按日期查看任务历史，包括已经标记为“已处理”的任务。

主页另一个“近期活动”区域记录的是项目历史变化，不是另一套任务进度。3.1.0 的名称容易混淆；看到项目创建、状态改变或输出路径登记时，不要把它当成后台任务结果。

## 在列表里看什么

任务按最近活动时间排序，新的在上面。卡片会显示任务类型、状态、阶段、开始时间、耗时和进度等摘要。

常见状态：

| 状态 | 含义 |
|---|---|
| 排队／运行中 | 后台流程还没有结束 |
| 等待批准 | Remis 需要你回到流程确认下一步 |
| 已完成 | 后台流程成功结束 |
| 失败／中断 | 流程已经结束，但需要检查或重新处理 |

部分失败在通用列表中目前会归入需要注意的失败状态；具体成功了什么、失败了什么，要在任务详情和所属业务页面确认。

## 打开任务详情

点击任务会打开与该 `taskId` 绑定的准确记录。页面首先给出：

- 当前阶段；
- 结果摘要；
- 建议下一步；
- 项目名称、游戏和任务类型；
- 开始、结束时间和创建者。

完整语言、供应商、模型和可编辑结果不一定在 Task Center 重复展示。点击项目入口或“返回工作流”，回到该任务所属页面继续处理。

技术日志默认折叠。普通摘要不足以判断问题时再展开；导出诊断日志前，注意其中可能包含项目内容或本机环境信息。

## 失败或结果不完整

先确认三件事：

1. 摘要是否明确说任务没有完全成功；
2. 已生成成果是否仍然可用或安全；
3. “下一步”把你带回哪个业务页面。

Task Center 目前不提供通用重试按钮，因为翻译、Model Arena、智能工坊等流程需要不同参数和确认。回到所属页面，按该功能自己的规则重试。涉及模型调用的重试必须再次确认。

3.1.0 尚未实现任务失败时的独立弹出警告。可以通过主页和 Task Center 的注意提示发现失败；如果怀疑状态没有刷新，点击刷新。

## “已处理”不是删除

终态任务可以点“已处理”，从 Task Center 收件箱移走。它仍保留在“全部日志”中，并显示已处理标记；从任务详情可以恢复。

运行中的任务不能标记为已处理。3.1.0 没有从 Task Center 删除任务历史、通用取消或整次重跑的入口。

## 哪些操作不会自动发生

Task Center 不会自动：

- 重试会产生费用的模型调用；
- 把失败改成成功；
- 删除历史或业务成果；
- 修改翻译文件或项目状态；
- 跳到另一个项目替你继续；
- 因为查看任务而重新执行工作。

如果未来增加取消、删除或整次重跑，这些操作必须先让你确认。
