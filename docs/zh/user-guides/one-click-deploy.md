# 一键部署：把汉化装进游戏

> 界面按钮：**「一键部署」**。  
> 对话框标题多为：**「清理假本地化与部署」**。  
> 作用：把译好的汉化包放到游戏会读取的 **Paradox 用户 mod 目录**，可选同时清理原版里的 **假本地化**。

**请优先用客户端功能**；只有内置路径探测失败或清理后仍异常时，再考虑手动复制文件夹。

假本地化的原理与备用手删步骤见 **[假本地化说明](fake-localization.md)**（本文偏「点哪里部署」）。

---

## 1. 什么时候用？

| 时机 | 是否部署 |
|------|----------|
| 初次翻译刚完成 | **是**，否则游戏可能读不到新包 |
| 增量翻译 / 校对 / 智能工坊改完 | **是**，让磁盘与游戏目录同步 |
| 只改了设置、没改译文 | 不必 |
| 还没翻译出输出包 | 会失败；先完成翻译 |

入口常见于：

- 翻译任务结束后的操作区  
- **项目管理** 项目页头部等处的 **一键部署**  

---

## 2. 推荐步骤

1. 确认项目已有 **翻译输出**（输出文件夹名 / 译好的 mod 包）。  
2. 点击 **「一键部署」**，打开部署对话框。  
3. 等待自动加载路径（或按提示刷新）。  
4. 核对两项路径（见下表）。  
5. 选择操作：  
   - **直接部署翻译**：只把汉化拷到目标目录  
   - **删除假本地化** 相关选项：先清原版假语言文件，再部署（或先清后部署，以按钮文案为准）  
6. 若清理假本地化：阅读 **高风险确认**，确认原始模组路径无误后再执行。  
7. 看到成功提示后，打开游戏启动器：启用 **原 Mod + 汉化**，检查 **加载顺序**。  
8. 进游戏抽查文本。

---

## 3. 对话框里的两个路径

| 字段（界面） | 含义 | 错了会怎样 |
|--------------|------|------------|
| **1. 目标部署目录** | 汉化包要放到的位置（Paradox 用户 `Documents\...\mod\...`） | 游戏找不到汉化，或装到错误游戏 |
| **2. 原始模组目录** | Steam 创意工坊 / 原版 Mod 路径；**清理假本地化时必填** | 清错 Mod，或清了也挡不住假文件 |

客户端通常会：

- 按游戏探测默认 Paradox mod 目录  
- 按项目元数据尝试探测创意工坊路径  

失败时：

- 用 **浏览…** 手动选文件夹  
- 或 **自动寻找原始模组**（若按钮可用）  

常见错误提示含义：

| 提示大意 | 处理 |
|----------|------|
| 未找到已翻译的模组文件夹 | 先完成初次/增量翻译 |
| 原始模组目录不存在 | 手动选对创意工坊/原版路径 |
| 无法确定 Paradox 用户模组目录 | 手动指定目标部署路径 |

---

## 4. 直接部署 vs 清理假本地化

| 操作 | 风险 | 何时选 |
|------|------|--------|
| **直接部署翻译** | 较低（写用户 mod 目录） | 首次安装汉化；或已确认无假本地化干扰 |
| **删除假本地化（并部署）** | **高**（改创意工坊/原版缓存） | 游戏里仍显示英文/假中文；加载顺序已正确 |

清理行为简述：在原始模组的 `localization`（或 `localisation`）下，**保留源语言**（如 `english`），删除其它语言文件夹及冲突文件。  
细节与 Steam 回拉问题 → [假本地化说明](fake-localization.md)。

也可单独使用 **「删除假本地化文件」** / **「删除路径下的假本地化文件」**（不经过完整部署时，以你版本按钮为准），同样需要正确原始路径与确认。

---

## 5. 部署成功后在游戏里

1. 启动器中启用 **原版 Mod** 与 **汉化 Mod**。  
2. 汉化排序应能 **覆盖** 原版（多数启动器中汉化在原版 **下方** / 更高优先级）。  
3. 仍英文 → 假本地化、冲突 Mod、部署到了错误游戏目录。  
4. 仍无效 → [日志](logs-and-diagnostics.md) 或 GitHub；手动步骤见假本地化文第 5 节。

---

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| 部署成功但游戏没有 | 启动器是否启用；是否装错游戏的 Documents 路径 |
| 每次更新后假中文又回来 | Steam 校验恢复文件；在 Remis 再清一次，或见假本地化「备用」 |
| 不敢点删除 | 可先 **直接部署** + 只调加载顺序；仍不行再清理 |
| 想改 Remis 程序 | 客户端不能改源码 → Issues |

## 7. 给帮助说明 / Copilot

用户说「怎么进游戏」「部署」「复制到 mod 文件夹」时：

1. **先** `open_deploy_dialog` / 说明点 **一键部署**  
2. 假中文 → 对话框内 **删除假本地化**（确认后），不要先甩手删教程  
3. 写操作必须用户确认  
4. 内置失败再链 [假本地化](fake-localization.md) 手动节  

相关 action 草案：`deploy_mod`、`clean_fake_localization`、`clean_fake_loc_and_deploy`、`open_deploy_dialog`。
