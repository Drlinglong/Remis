# 一键部署：把翻译成果复制到游戏启动器可读取的位置

> 界面按钮：**「一键部署」**。
> 作用：把当前项目已有的翻译成果复制到对应游戏的 Paradox 用户 `mod` 目录。

部署完成后，Remis **不会**替你操作游戏启动器。你仍需自己把本地 Mod 加入播放列表、
调整加载顺序并启动游戏。

假本地化是另一项高风险操作。需要时请读
[假本地化说明](fake-localization.md)。

---

## 1. 什么时候可以部署？

只要当前项目已经生成可用翻译成果，就可以考虑部署：

| 当前状态 | 是否可以部署 |
|---|---|
| 初次翻译完全成功 | 可以 |
| 初次翻译或增量翻译部分成功 | 有可用输出时可以；部分内容可能仍是原文 |
| 校对或智能工坊刚修改了成果 | 可以重新部署，让本地 Mod 与最新成果同步 |
| 翻译百分之百失败或没有输出 | 不可以；先重新翻译 |
| 只改了设置，没有产生新成果 | 通常不需要 |

校对不是部署的强制步骤。如果你觉得初译已经够用，可以先部署进游戏体验，再决定是否
继续校对。

入口通常位于：

- 翻译任务的结果页；
- **项目管理**中的项目概要或项目菜单。

---

## 2. 部署会做什么？

Remis 会：

1. 找到当前项目的翻译输出；
2. 找到对应游戏的 Paradox 用户 `mod` 目录；
3. 显示实际源位置和目标位置；
4. 经你确认后复制整个项目输出；
5. 为需要的游戏生成或更新启动器描述文件；
6. 返回成功、警告或失败结果。

典型目标位置类似：

```text
Documents/
└── Paradox Interactive/
    └── <游戏名称>/
        └── mod/
            └── <Remis 翻译成果>/
```

Windows 下，Remis 也会检查 OneDrive 中的 `Documents`。当前版本自动选择可信目标，
目标路径在部署窗口中是只读的，不能把项目随意部署到其它文件夹。

Remis 不会：

- 修改 Steam 创意工坊文件或原始 Mod；
- 自动清理假本地化；
- 打开或操作 Paradox 游戏启动器；
- 把本地 Mod 加入播放列表；
- 调整加载顺序；
- 自动启动游戏。

---

## 3. 推荐步骤

1. 在翻译结果页或项目概要中点击 **「一键部署」**。
2. 等待 Remis 生成部署预览。
3. 核对：
   - 当前项目和翻译输出；
   - Paradox 用户 `mod` 目标位置；
   - 是否会替换同名旧部署。
4. 如果目标已经存在，阅读覆盖警告并勾选确认。
5. 点击 **「直接部署翻译」**。
6. 查看结果：
   - 成功：文件已复制；
   - 警告：文件可能已复制，但启动器描述文件需要检查；
   - 失败：本次部署没有完整完成，按提示查看日志并重试。
7. 打开 Paradox 游戏启动器。
8. 把 Remis 生成的本地 Mod 加入你的播放列表。
9. 启用原 Mod 和翻译 Mod，并调整加载顺序。
10. 启动游戏抽查文本。

当前版本若检测到项目存在格式验证错误，会阻止部署并引导你先处理错误。

---

## 4. 覆盖已有部署

重新部署同一个项目时，目标位置可能已经存在旧版本。

Remis 会显示覆盖警告，并要求你单独确认。未确认时不会开始部署。

确认后，当前实现会替换整个同名目标文件夹，而不是只复制变化的文件。部署过程不是
可回滚事务；如果复制途中失败，Remis 目前不能保证旧部署仍然完整。因此：

- 部署失败时不要假设旧版本一定还能使用；
- 重新打开部署窗口，生成新预览后再重试；
- 需要排查时查看[日志与诊断](logs-and-diagnostics.md)。

---

## 5. 部分翻译成果

部分成功的翻译可能在失败位置保留源语言原文，因此通常仍能进入游戏体验。

产品规则是：这类成果允许部署，但部署前应醒目提示“部分内容仍是原文”并要求再次
确认。**3.1.0 的部署窗口还没有完整实现这条专门提示。**

部署部分成果不会把失败原文保存成数据库译文，也不会把该成果自动变成完整翻译基线。

---

## 6. 部署成功后为什么还没在游戏里看到？

“部署成功”只表示 Remis 已经把文件放到启动器会读取的位置，不表示启动器已经启用它。

请依次检查：

1. 本地翻译 Mod 是否出现在启动器中；
2. 是否已加入当前播放列表；
3. 原 Mod 和翻译 Mod 是否都已启用；
4. 翻译 Mod 的加载顺序是否能覆盖原 Mod；
5. 是否有假本地化或其它 Mod 冲突。

需要清理假本地化时，请使用独立的
[假本地化清理流程](fake-localization.md)。部署确认不会自动授权清理。

---

## 7. 常见结果

| 结果 | 含义 | 下一步 |
|---|---|---|
| 部署成功 | 文件已复制到 Paradox 用户 `mod` 目录 | 打开启动器，加入播放列表并调整顺序 |
| 文件已复制，但启动器可能无法识别 | 描述文件缺失或需要检查 | 查看目标文件和日志 |
| 目标已存在 | 需要单独确认替换 | 核对目标后勾选覆盖确认 |
| 部署预览已失效 | 项目、源或目标可能已经变化 | 重新打开窗口生成预览 |
| 存在格式验证错误 | 当前版本会阻止部署 | 返回验证或智能工坊处理 |
| 部署失败 | 可能是路径、磁盘、文件占用或安全检查问题 | 查看日志，生成新预览后重试 |
