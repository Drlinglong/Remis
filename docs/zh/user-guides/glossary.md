# 词典与词汇表：怎么用

> 侧栏入口：**质量与术语 → 词汇表管理**。
> 术语表用来统一人名、地名、专有名词、机制名和缩写。它是稳定正式功能。

## 术语表适合管什么

适合收录：

- 人名、地名、组织名和阵营名；
- 游戏机制名、世界观设定和 Mod 独有名词；
- 缩写及同一术语的拼写变体；
- 完全固定、整体不可拆分的句子，例如 `en taro tassadar`。

通常不要收录：

- 阵营口吻、角色语气和整体文风——这些属于翻译风格与校对；
- 普通固定句式或只出现一次的普通句子；
- `$COUNTRY_NAME$`、`[Concept('...')]` 等脚本标识；
- 需要按上下文自由翻译的普通多义词，除非备注清楚写明适用范围。

最好在翻译前准备好术语。任何时候都可以回来维护，但修改只影响未来翻译，不会自动
改变已经生成的译文。

## 三类词典

| 类型 | 默认行为 | 典型用途 |
|---|---|---|
| 全局主词典 | 对当前游戏默认加载 | 游戏通用官方／社区术语 |
| 项目词典 | 与当前项目绑定并默认加载 | 当前 Mod 特有名词 |
| 手动选择的额外词典 | 在翻译高级选项中主动选择 | 主题包、系列 Mod 或临时覆盖 |

产品规定的目标优先级是：

> 手动选择的额外词典 > 项目词典 > 全局主词典

翻译入口按这一顺序解决同一源词的冲突。因为这种冲突很少见，Remis 不会用高风险警告
打断流程；需要临时覆盖项目现有词典时，再手动选择额外词典即可。

## 新增、编辑和删除词条

1. 打开 **词汇表管理**。
2. 选择游戏、目标语言和一本词典。
3. 新增或打开一个词条，填写源文本、译文和备注。
4. 保存后，以界面明确显示成功为准。

常用字段：

| 字段 | 用途 |
|---|---|
| 源文本 | 原文术语 |
| 译文 | 对应语言的优先译法 |
| 备注 | 适用领域、语境和例外条件 |
| 变体 | 复数、别名或其它拼写 |
| 缩写 | 需要识别的简称 |

删除单个词条或整本词典前，Remis 会要求确认。删除整本词典会同时删除其中词条；若它
绑定项目，还会影响项目绑定。Remis 不保存旧词典版本，不能指望在词典页面一键回滚。

## 翻译时怎样使用

在初次或增量翻译的配置中：

- 保持 **使用主词典**，让当前游戏的通用术语生效；
- 项目已绑定项目词典时，Remis 会自动带上；
- 如需主题词表或临时覆盖，在高级选项中手动选择额外词典。

开始翻译前，仍应检查项目、目标语言、供应商和模型。词典冲突属于低风险事项，不会
阻止翻译。

## 术语不是机械替换

词典译法是上下文优先的参考。备注尤其重要。

例如 `silo → 发射井` 的备注写着“仅用于军事领域的导弹发射井”：

- 农场和麦子语境应译为“筒仓”；
- 明确储存、发射导弹的 `missile silo` 应译为“发射井”。

如果模型无视明确备注，可能是提示词、程序或模型能力问题，不代表词条没有保存成功。
保存成功只说明术语已经进入最新词典。

## 修改后会发生什么

- 下一次翻译读取最新词典；
- 已有翻译不会自动变化；
- Remis 不会因为保存词条而调用模型、重翻、校对或部署；
- 如需统一旧成果，应重新处理相关内容或在校对页人工修改。

在校对阶段才发现术语不统一时，仍可补词典，但整本重翻可能很贵。可以先判断影响范围，
再选择局部重处理或人工校对。

## 项目词典和新词审判

项目管理中的 **项目词典** 页签可以创建、绑定、解除绑定和打开词典。界面可以列出全部
游戏的词典并按游戏筛选，但 3.1.0 后端只允许把同一游戏的词典绑定给项目。

建议在开始翻译前运行新词挖掘机，让它先找出原文里的新造专名和概念词。新词审判庭是
它的人工审批环节：所有 AI 找出的新词都必须由用户批准，才会写入项目词典。

新词挖掘开始时，Remis 可以自动准备一本项目词典；这不等于自动接受新词。项目词典是
审批流程的最终产物，默认绑定当前 Mod，并在该项目翻译时自动使用。

解除绑定不会删除整本词典，也不会修改已有译文。普通绑定与解除绑定是可撤销的低风险
操作，不需要二次确认；把项目词典改成公共／全局词典会扩大影响范围，必须先确认。

## 合并与批量操作

合并词典前，界面会预览目标、词条数和冲突，并让用户选择冲突策略。合并会写目标词典，
不会把“模型觉得合理”当作默认冲突决定。

当前没有批量导入功能。批量删除使用预览和确认；合并作为后台任务运行，可在 Task
Center 查看结果。若任务没有完全成功，应检查结果摘要和失败信息后再重试。

## 常见问题

| 问题 | 处理 |
|---|---|
| 保存了词条，旧译文没变 | 正常；词典只影响未来翻译，旧成果需重处理或校对 |
| 同一术语仍然乱译 | 检查是否加载正确词典、备注是否清楚，以及三层词典是否冲突 |
| 模型没有照搬词典 | 先检查上下文是否与备注冲突；多义词不应机械替换 |
| 项目词典绑定失败 | 确认项目与词典属于同一游戏 |
| 新词为什么没进词典 | 候选需要在新词审判庭审批 |
| 删错词条或词典 | 当前没有词典历史版本；删除前务必确认 |
