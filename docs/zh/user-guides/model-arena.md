# 模型竞技场：正式翻译前先做小样对比

> 侧栏入口：**「翻译工作流 → 模型竞技场」**。

模型竞技场用于在正式翻译整个项目之前，对同一批代表性原文比较两个或三个模型。模型身份在选择阶段保持匿名，避免品牌印象影响判断；完成选择后再查看模型、偏好次数、理由、格式错误和耗时。

## 适合什么时候使用

- 第一次为大型项目选择翻译模型。
- 更换模型或提示词后，希望先比较小样。
- 想确认更贵的模型是否真的带来可见收益。

模型竞技场不会替你启动正式翻译，也不会自动修改项目文件。完成比较后，返回初次翻译或增量翻译页面选择最终方案。

## 基本流程

1. 选择项目、目标语言和代表性样本。
2. 选择两个或三个候选模型。
3. 启动匿名试译。
4. 逐条选择更好的结果，或标记平局、全部不合格。
5. 查看汇总结果，再决定正式翻译使用的模型。

模型调用可能产生费用，启动前请确认提供商、模型与样本规模。分享结果前使用导出预览，检查其中是否包含不希望公开的项目文本。
