# 常见问题 (FAQ)

欢迎来到 Project Remis！本 FAQ 面向使用 **打包客户端** 的用户，帮助快速上手并排查常见问题。

> **第一次用？** 请先读 **[从零开始：第一次汉化](getting-started.md)**。  
> 正确顺序是：**项目管理 → 创建新项目**，再进入 **初次翻译** 选中该项目。  
> 不要在没有项目时，指望单独点「初次翻译」完成建档。

> **API 填哪里？** 见 **[Provider 配置速查](provider-setup-index.md)**（优先在客户端 **设置 → API** 填写，不要改源码）。

---

## 1. 安装与启动

### Q1.1：如何下载和启动 Project Remis？
**A：**
1. 到 [GitHub Releases](https://github.com/Drlinglong/Remis/releases)（或你获取安装包的渠道）下载当前版本的安装包 / 便携包。  
2. 按发布说明安装或解压后启动 **Remis 客户端**（Tauri 封装的桌面应用）。  
3. 启动后先看主页；要开始汉化请点 **「开始新的翻译项目」** 或左侧 **「项目管理」**。

> 若你拿到的是面向开发者的源码仓库，启动方式与客户端不同，请参阅开发文档；**普通汉化用户请用发布版客户端。**

### Q1.2：还要运行 `setup.bat` / `run.bat` 吗？
**A：** **发布版客户端一般不需要。**  
这些脚本多用于早期 CLI / 开发环境。你应直接启动 Remis 应用，并在 **设置 → API** 里配置密钥与模型。

### Q1.3：为什么我需要 API Key？如何设置？
**A：** Remis 本身不提供翻译算力，需要你自备 AI 服务（Gemini、OpenAI 兼容接口、Ollama 本地模型等）。

* **获取**：到对应服务商网站申请 API Key / Token（部分本地方案可无云端 Key）。  
* **设置（推荐）**：客户端 **设置 → API**，选择供应商，填写密钥、模型，必要时填写 Base URL，保存。  
* **速查**： [Provider 配置速查](provider-setup-index.md)  
* ⚠️ 申请 Key 可能需绑定支付方式；使用可能产生费用；**不要把完整 Key 发到公开 Issue 或聊天里**。

### Q1.4：密钥存在哪里？还是环境变量吗？
**A：** 打包客户端通常把配置保存在本机用户数据目录中（由应用读写），**优先用设置页保存**，不必再依赖 `setup.bat` 写系统环境变量。  
若某高级/旧文档仍写「环境变量 / 改 `app_settings.py`」，那是开发者或历史路径；客户端用户以设置页为准。

## 2. 项目与 Mod 从哪来

### Q2.1：Mod 文件应该放在哪里？
**A：** **不必**再把 Mod 丢进程序旁边的 `source_mod` 再启动（那是旧工作流）。

正确做法：

1. 打开 **项目管理 → 创建新项目**  
2. **文件夹路径** 选你的 **Mod 根目录**，或 Steam 创意工坊目录，例如：  
   `...\steamapps\workshop\content\<游戏ID>\<物品ID>\`  
3. 选择导入方式：  
   - **复制到 Remis**：拷贝本地化等材料到工作区  
   - **原位使用**：直接引用该目录（大 Mod 常用）  

详见 [从零开始](getting-started.md)。

### Q2.2：创意工坊文件夹是一串数字，要改名吗？
**A：** 创建项目时 **项目名称** 可以起好认的名字（如 Mod 原名）；磁盘上的创意工坊数字目录 **可以不改名**。路径选对即可。

### Q2.3：程序识别不了 / 创建项目失败怎么办？
**A：**
1. 确认选的是 **完整的 Mod 根目录**（内含 `localization` 或 `localisation` 等），不是单个 yml。  
2. **游戏** 与 **源语言** 是否选对。  
3. 路径是否仍存在、是否有读取权限。  
4. 仍失败：看 [日志与诊断](logs-and-diagnostics.md)，或到 GitHub 反馈。

## 3. 翻译过程

### Q3.1：如何选择游戏、语言和 AI 服务？
**A：**
1. **游戏 / 源语言**：在 **创建项目**（或项目设置）时选定；翻译页里常为只读。  
2. **目标语言、API 供应商、模型**：在 **初次翻译** 选中项目后的配置步骤中选择。  
3. 可填写 Mod 主题 / 额外提示，并选用词典。  

总流程见 [从零开始](getting-started.md)。

### Q3.2：什么是词典？它有什么用？
**A：** 词典规定游戏术语的标准译法（如专有名词），减少前后译名不一致。可在翻译配置中启用主词典或额外词典；也可在 **词汇表管理** 中维护。

### Q3.3：翻译完成后，汉化包在哪里？
**A：**
* 在 **项目管理** 中查看该项目的 **翻译输出目录**（可用「打开翻译文件目录」类按钮）。  
* 也可用 **一键部署** 直接装到游戏可读的 Paradox 用户 `mod` 目录，而不必先手动翻找输出文件夹。  

### Q3.4：Mod 更新了，还要全盘重翻吗？
**A：** 一般 **不需要**。请用 **增量翻译**：复用已有译文，只处理新增/修改条目。  
前提是项目已有 **归档基线**（初次翻译完成，或半成品做过 **翻译上载**）。  
详见 [增量翻译](incremental-update.md) 与 [导入已有译文](import-existing-translations.md)。

### Q3.5：别人做好一半的汉化，怎么接到 Remis？
**A：** 创建/选好项目并挂上译文目录后，到 **项目管理 → 历史**，执行 **「翻译上载」**，把磁盘上的译文写入数据库归档，再去做增量或继续翻译。  
详见 [导入已有译文](import-existing-translations.md)。

## 4. 游戏内启用

### Q4.1：如何将汉化 Mod 放到游戏能读取的位置？
**A：** **优先使用 Remis 的「一键部署」**（对话框多为「清理假本地化与部署」）。完整步骤见 **[一键部署](one-click-deploy.md)**。

仅当一键部署不可用时，再手动复制汉化包到例如：
* **维多利亚3**: `Documents\Paradox Interactive\Victoria 3\mod`
* **群星 (Stellaris)**: `Documents\Paradox Interactive\Stellaris\mod`
* **钢铁雄心4 (HOI4)**: `Documents\Paradox Interactive\Hearts of Iron IV\mod`
* **十字军之王3 (CK3)**: `Documents\Paradox Interactive\Crusader Kings III\mod`

若部署后仍显示英文，请同时处理假本地化：**[假本地化说明](fake-localization.md)**。

### Q4.2：如何在游戏启动器中启用 Mod？
**A：** 启动游戏启动器，进入「播放集」或「Mod 管理」界面。您需要同时启用 **原 Mod** 和 **汉化 Mod**。

### Q4.3：为什么汉化 Mod 的加载顺序很重要？
**A：** **这是一个关键步骤！** 在游戏启动器中，请务必确保 **汉化 Mod** 在列表中的排序 **低于** 原 Mod（或按启动器规则使其覆盖原版）。这样汉化才能盖住原文。

### Q4.4：什么是假本地化（假中文）文件？我为什么要删除它们？
**A：** 假本地化是原版 Mod 里「假装成中文（或其他语言）、内容仍是原文」的文件。它们能让没汉化的玩家勉强看到英文，但往往会 **挡住真正的汉化包**。

**请优先使用 Remis 内置功能（不要先手动删文件夹）：**
1. 翻译完成后，打开 **「一键部署」**（对话框多为 **「清理假本地化与部署」**）。  
2. 确认 **目标部署目录** 与 **原始模组目录**。  
3. 需要时使用 **删除假本地化** 相关按钮，并在风险确认后执行。  
4. 启动器启用原 Mod + 汉化，检查加载顺序。  

完整说明：**[假本地化说明](fake-localization.md)**。

## 5. 常见问题与故障排除

### Q5.1：程序闪退或报错怎么办？
**A：**
* **API Key / 网络**：检查设置页密钥、额度、网络。  
* **Mod 不完整**：确认导入的是完整 Mod 根目录。  
* **日志（打包客户端）**：`%APPDATA%\RemisModFactory\logs\`，优先看 `remis_backend.log` 末尾 `ERROR`。详见 [日志与诊断](logs-and-diagnostics.md)。  
* **校验红字**：见 [错误目录](error-catalog.md)。

### Q5.2：翻译后在游戏中不生效怎么办？
**A：**
1. **一键部署** 是否成功。  
2. **删除假本地化**（内置流程）。  
3. **加载顺序** 与是否启用了汉化。  
4. 排除其它冲突 Mod。  
5. 仍无效：假本地化专文的手动备用，或带日志去 GitHub。

### Q5.3：翻译质量不佳怎么办？
**A：**
1. 在客户端维护 **词典 / 词汇表**，统一术语。  
2. 翻译配置里补充 **Mod 主题 / 额外提示**。  
3. 关键文本用 **[校对](proofreading.md)** 手改；变量/标签等格式问题用 **[智能工坊](agent-workshop.md)**。

### Q5.4：API Key 提示无效或配额不足怎么办？
**A：**
* **无效**：检查设置页 Key 是否多空格、是否选对供应商、Base URL 是否正确。  
* **配额 / 429**：服务商额度或频率限制；降低并发/RPM 或等待刷新。  
* **网络**：代理、防火墙、地区限制。  
* 详见 [Provider 速查](provider-setup-index.md) 与 [日志](logs-and-diagnostics.md)。

### Q5.5：还有问题或想要新功能？
**A：**
* 反馈：<https://github.com/Drlinglong/Remis/issues>  
* 请附：现象、步骤、版本、系统，以及 **已打码** 的日志片段。  
* 打包客户端 **无法修改 Remis 源码**；功能与缺陷由维护者修复合入发布版。
