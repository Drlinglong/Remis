# Remis 3.2.1 更新日志（未发布）

准备日期：2026-09-11。本文件记录待发布代码；未创建 Release、标签或安装包，尚未推送。仅更新 stable 版本，独立 Agent Preview 通道仍保留原版本。

## 新增与改进

- Agent API 支持自定义语言套壳翻译；实际语言、游戏语言壳和输出前缀随计划、任务、重试保留。MCP 翻译计划也可传递套壳配置。
- Agent API 接入现有 Steam 工作台：读取源描述、生成意大利语等目标语言描述、保存和选择描述/封面版本。不会自动向 Steam 发布。
- 初次翻译选择套壳后显示非阻塞建议；项目管理发现 custom 归档时显示可展开说明。强烈建议每种实际套壳语言单独维护项目，不增加创建项目的必填项，不禁止官方多语言共存。
- Agent 可在用户明确授权后检查和少量修订本地化文件；新增受限基线同步入口，将指定条目的当前文件值同步回任务对应语言的归档。路径绑定任务输出，校验文件哈希，不接受任意数据库写入。
- 源目录说明提示增量更新后目录名称可能不变，版本应依据内容和更新记录判断。
- 本次新增提示统一采用面向玩家的解释，说明翻译记录混用会影响后续 Mod 更新；补齐现有 11 种界面语言。用户指南、Operator Skill 和 Copilot 操作说明要求先解释影响和操作，再按追问展开技术细节。

## 修复

- 翻译文件进度与批次进度分开，旧任务没有文件计数时返回未知，不再把批次数当文件数。
- 修复开发后端退出时未关闭异步数据库连接造成的热重载挂起；增加 backend-only 启动入口，避免 API 操作反复拉起可见命令行窗口和前端。
- 修复套壳开关的事件处理位置，使切换时的目标选项和自定义字段清理生效。
- 修复 Victoria 3 的 Concept 显示文字误报：允许翻译第二个参数，仍保护第一个概念键、修饰符、出现次数、嵌入变量/图标及格式绑定。结构与变量数量校验共用身份规则；CK3 同步加强嵌入内容保护。仅用于校验比较，不改写源文或模型输入。

## 已知限制与发布前复核

- 格式修复后 Agent 校验侧文件仍可能显示旧结果；基线同步接口明确返回 validation_refreshed=false，不冒充重新校验。
- 格式修复进度 successful_batches 仍可能承载错误记录数；单条翻译多种错误仍有重复处理记录。
- 意大利语尚无专用词典或标点规则。Concept 显示词误报已修复；其他运行时表达式仍严格检查，按源变量顺序修复有时损害自然语序。
- 2026-09-12 意大利语交付复核：人工调整 28 条效果/建筑/部队标题及说明的语序，经 Agent 基线同步接口保存 28 条。当前校验器对其中合法的引用换序产生 48 条 error 记录；逐条检查确认引用内容、数量和格式绑定未变，另有原有 12 条 warning。此结果不能表述为自动校验零错误，也不应运行格式修复来撤销已审核的语序调整。后续应区分独立引用的换序与真正的引用损坏/绑定变化。
- 原 Mod 的都市派动态名称可能在集团尚未启用时显示为 Politically Unaligned ()。源表达式与翻译包一致；本次保留动态逻辑，触发条件仍需游戏存档对照确认，不据此修改原 Mod。
- 初次翻译归档仍含目录身份与名称回退机制；独立项目可隔离本次记录，但更名/身份复用仍应专项验证。
- Mod metadata 探测可能漏报 .metadata/metadata.json；生成翻译 metadata 仍可能沿用原工坊 ID，上传独立翻译 Mod 前应复核。本次意大利语成果已人工换用独立本地 ID。
- 尚未进行安装包构建、签名、完整回归或游戏内加载测试。不得将本记录视为正式发布批准。
